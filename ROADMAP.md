## Constraints
- Spec-first workflow; no breaking change without spec updates.
- No new features until release blockers are resolved.
- Base install stays slim; research dependencies remain optional.
- Research outputs are machine-generated (no hand edits to results.json).
- Recordings are not checked into the repo (store links or pointers only).
- Record a timestamp for each phase start and conclusion (ISO 8601 UTC).

## Research Standard (Adopted)
Experiment package layout:
- README.md (experiment card)
- manifest.yaml (reproducibility metadata; see research/SCHEMA.md)
- results.json and results.csv (generated by scripts)
- analysis.md (interpretation)
- artifacts/ (plots, figures, tables)
- recordings/ (README with external pointer only)

Repository index:
- research/INDEX.md generated by scripts/research_index.py from manifests.

Source of truth:
- recordings -> scripts/research_export.py -> results.json/results.csv
- manifest.yaml -> scripts/research_index.py -> INDEX.md
