## Drift Issues

1. **RE1**: README.md presence not enforced
   - **Description**: Validator only checks for manifest.yaml.
   - **Impact**: Experiment cards can be missing without detection.
   - **Recommended Fix**: Add README.md presence check in research_validate.

2. **RE2**: No provenance check for results.json/results.csv
   - **Description**: Validator does not confirm results were generated by research_export.py.
   - **Impact**: Manual edits can drift from recordings.
   - **Recommended Fix**: Add validation that results.json schema matches export format and include a generator signature.

3. **RE5**: Results schema_version not validated
   - **Description**: Export sets schema_version, but validator never checks results.json.
   - **Impact**: Results files can drift to invalid schema versions.
   - **Recommended Fix**: Extend validator to read and validate results.json schema_version.

4. **RE6**: Recordings directory constraints not enforced
   - **Description**: Validator does not inspect recordings/ contents.
   - **Impact**: Raw recorder JSON could be committed inadvertently.
   - **Recommended Fix**: Add recordings/ scan to enforce pointer-only policy.

5. **RE8**: Export outputs are not strictly deterministic
   - **Description**: results.json includes generated_at timestamp.
   - **Impact**: Output differs across runs with identical inputs.
   - **Recommended Fix**: Allow deterministic mode or omit generated_at when comparing outputs.
