# AgentDeck Core 0.3.0

AgentDeck Core 0.3.0 narrows the package to an evidence-grade execution
substrate for AI agents. AgentDeck owns execution truth; downstream systems
such as Quaist own corpus selection, measurement, interpretation, and claims.

## Breaking Changes

- Removes the public `agentdeck.research` package, research CLIs, custom
  behavioral scorers, and curation helpers from the active package.
- Requires a line-anchored `ACTION: <value>` declaration. Controllers no longer
  infer decisions from incidental action words in reasoning or narration.
- Changes the base `Player` model default from `gpt-4` to `unspecified`.

The historical Agentic Edge research workflow and its exact APIs remain
available at the `agentic-edge-research` tag.

## Execution Truth

- Records exact provider-call messages, SDK arguments, attempts, response
  completion status, stop reason, and provider-reported identity when exposed.
- Records explicit decision attribution and retains failed or truncated calls
  without converting them into inferred actions.
- Records effective Game and Player configuration plus a content-addressed Game
  implementation identity when source is available.
- Makes MockPlayer identity explicit and includes untracked files in repository
  dirty-state reporting.

## Compatibility Notes

- Research consumers should pin the historical tag while equivalent research
  capabilities are re-derived in Quaist.
- Custom Players that previously relied on bare action tokens must emit
  `ACTION: <value>`.
- Direct Record consumers should tolerate the new additive provider-call and
  implementation-provenance fields.
