# Human Run Notes

Use this directory for human decisions that affect interpretation:

- budget approvals and pruning decisions
- provider/model availability notes
- pilot anomalies
- S2 controller lock decision, if S2 is added
- exact FixedDamage replication package selection
- P2 expansion rationale

Keep generated logs under `agentdeck_runs/` while executing, then move raw
recordings to external storage before publication.
