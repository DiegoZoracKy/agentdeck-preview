# Analysis

This directory is the authored interpretation workspace for the research package.

AgentDeck treats humans and AI agents as first-class analysis authors. Each
analysis MUST live in its own timestamped subdirectory so multiple independent
reviews can coexist without overwriting each other.

Directory names use the same timestamp core as runtime session IDs:
`YYYYMMDD_HHMMSS`. Use the `analysis_` prefix for grep-friendly discovery:
`analysis_YYYYMMDD_HHMMSS_<author>_<topic_slug>`. The author token should be a
stable human or agent identifier such as `codex`, `claude`, or a lowercase
username. The topic slug should be lowercase ASCII snake_case.

## Agent Quickstart

If you are asked to analyze this experiment and generate a report:

1. Read the package root `README.md`, `manifest.yaml`, `matrix.yaml` when
   present, and `results.md`.
2. Inspect cell-level artifacts under `artifacts/<cell_id>/results.json` for
   any quantitative claim that depends on a specific cell, seat split, cost, or
   behavioral profile.
3. Create a new timestamped subdirectory:
   `analysis/analysis_YYYYMMDD_HHMMSS_<author>_<topic_slug>/`.
4. Write the main report as `analysis.md` inside that subdirectory.
5. Add `provenance.yaml` listing author identity, source artifacts, and review
   status.
6. Put optional supporting files under `support/`.

Do not edit generated artifacts, sibling analyses, or legacy top-level
`analysis.md` files unless the user explicitly asks for that maintenance work.

Recommended layout:

```text
analysis/
├── README.md
└── analysis_YYYYMMDD_HHMMSS_<author>_<topic_slug>/
    ├── analysis.md
    ├── provenance.yaml
    └── support/
```

Examples:

```text
analysis/analysis_20260119_141522_codex_main_findings/
analysis/analysis_20260120_093004_claude_seat_effects/
analysis/analysis_20260121_184450_diego_presentation_notes/
```

## Required Provenance

Each authored analysis subdirectory SHOULD include `provenance.yaml`:

```yaml
author:
  name: Codex
  type: ai # ai|human
  model: GPT-5
created_at: 2026-01-19
analysis_type: findings_review
llm_assisted: true
review_status: draft # draft|reviewed|final
source_artifacts:
  - ../../results.json
  - ../../results.md
  - ../../artifacts/<cell_id>/results.json
```

## Rules

- Treat `results.json`, `results.csv`, and `results.md` as generated artifacts.
- Do not hand-edit generated artifacts.
- Cite artifact paths for quantitative claims.
- Prefer cell-level claims over heterogeneous package aggregates.
- Use `results.md` as the first human-readable factual source, then verify
  important numbers against `results.json` or cell artifacts.
- Separate confirmed findings, caveats, and speculation.
- Call out position effects, provider/model drift, LLM nondeterminism, cost
  assumptions, and scorer limitations when relevant.
- AI-authored analysis is allowed and expected, but it is interpretation, not
  canonical fact.

`results.md` is the canonical human-readable factual report generated by
AgentDeck. This directory is for interpretation and presentation work built on
top of that report.
