# Hidden Signal: inspection under hidden and visible information

This small current-architecture Study is the orthogonal Miningames Gate A
acceptance reference. It is deliberately unlike The Agentic Edge:

- one Player;
- no opponent, rank, or winner;
- no health, combat, or resource-recovery semantics;
- fresh Recorder v2 execution using a local deterministic calibration Player;
- a behavioral Measure based on inspection before commitment, not outcome.

The authored Study is immutable source. Every execution, Record corpus,
Evidence artifact, Finding, and Stage projection is written outside this
directory.

Run the complete workflow from the repository root:

```bash
python research/references/hidden-signal/reproduce.py --output /tmp/hidden-signal
```

The output contains fresh canonical Records, a content-addressed analysis,
Evidence, an authored Finding, a deterministic reference report, and a Match
Surface artifact for the bundled Stage.

The calibration policy is intentionally simple: inspect when the signal is
hidden; otherwise commit to the visible signal. Its purpose is to prove the
Research architecture and an explicit unavailable path, not to make a claim
about a model or a general behavioral construct.
