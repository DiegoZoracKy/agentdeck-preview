# AgentDeck Pricing System Specification

> Status: Final
> Version: 1.0.1
> Last Updated: 2026-03-17
> Implementation: Complete (Phase 6-8 compliance verified)
> Review State: Legacy-approved
> Audience: Core developers, LLM integration authors, cost tracking spectators

---

## 1. Purpose

This specification defines AgentDeck's pricing system for calculating LLM API costs. The system must:

- **Centralized pricing data** - Single YAML file for all provider/model costs
- **Defensive validation** - Catch typos and malformed data early
- **Zero-cost fallback** - Never crash on missing pricing (log warnings instead)
- **Multi-provider support** - OpenAI, Anthropic, Google, and future providers
- **Cost transparency** - Enable TokenUsageTracker spectator to show real costs

---

## 2. Terminology

| Term | Meaning |
|------|---------|
| **Provider** | LLM service provider (e.g., "openai", "anthropic", "google") |
| **Model** | Specific model identifier (e.g., "gpt-4o-mini", "claude-3-5-sonnet-20241022") |
| **Input tokens** | Tokens sent to the LLM (prompt, context, system message) |
| **Output tokens** | Tokens generated by the LLM (response, completion) |
| **Cost per million** | Pricing unit used by providers (USD per 1M tokens) |

---

## 3. Architecture

### 3.1 Components

```
pricing.yaml (YAML file)
    ↓ loaded by
pricing.py (Python module)
    ├── load_pricing_data() → Dict
    ├── get_model_pricing(provider, model) → (input_cost, output_cost)
    └── calculate_cost(provider, model, prompt_tokens, completion_tokens) → float
    ↓ used by
LLMPlayer (captures usage_info metadata)
    ↓ metadata flows to
TokenUsageTracker (spectator)
    └── displays costs per player/model
```

### 3.2 Data Flow

1. **Startup**: pricing.py loads pricing.yaml on first use (cached globally)
2. **Validation**: YAML structure validated before caching
3. **API Call**: LLMPlayer calls OpenAI/Anthropic/Google API
4. **Metadata**: LLMPlayer captures `usage_info = {prompt_tokens, completion_tokens}`
5. **Cost Calculation**: TokenUsageTracker calls `calculate_cost(provider, model, prompt_tokens, completion_tokens)`
6. **Display**: TokenUsageTracker shows `$X.XX` per player/model

---

## 4. YAML Schema (pricing.yaml)

### 4.1 File Location

**Path**: `src/agentdeck/config/pricing.yaml`

**Rationale**: Placed in `src/agentdeck/config/` (not project root) so it's included when AgentDeck is installed as a package.

### 4.2 Schema Structure

```yaml
# Provider-based structure
<provider>:  # e.g., "openai", "anthropic", "google"
  <model>:   # e.g., "gpt-4o-mini", "claude-3-5-sonnet-20241022"
    input_cost_per_million: <float>   # USD per 1M input tokens
    output_cost_per_million: <float>  # USD per 1M output tokens
    last_updated: "<YYYY-MM-DD>"      # Optional: pricing date
    tier: "<string>"                   # Optional: provider tier (e.g., "standard", "batch")

  _default:  # Optional: fallback for unknown models in this provider
    input_cost_per_million: <float>
    output_cost_per_million: <float>

metadata:    # Optional: YAML-level metadata
  last_updated: "<YYYY-MM-DD>"
  updated_at: "<YYYY-MM-DD>"
  sources:
    - "<string>"
```

### 4.3 Validation Rules

**V0: Root Structure** (critical)
The YAML root MUST be a dict/mapping. If pricing.yaml contains a list, scalar, or null at the top level, validation MUST raise ValueError BEFORE attempting to iterate. This prevents AttributeError and ensures "fail fast & loudly" behavior.

**V1: Required Fields**
Every model entry MUST have `input_cost_per_million` and `output_cost_per_million`.

**V2: Type Safety**
Cost fields MUST be numeric (int or float), not strings.

**V3: Non-Negative Costs**
Cost fields MUST be >= 0.0 (negative costs are invalid).

**V4: Provider Structure**
Each provider MUST be a dict mapping model names to model data.

**V5: Metadata Exclusion**
The top-level `metadata` key is ignored during validation (reserved for YAML metadata).

**V6: Special Keys**
Keys starting with `_` (e.g., `_default`) skip required field validation (used for defaults).

## 5. Packaging Requirements

### 5.1 Problem

Placing pricing.yaml under `src/agentdeck/config/` is NOT sufficient for distribution. By default, setuptools only includes Python files (`.py`) in wheels and sdists. Data files like `.yaml` must be explicitly declared in `pyproject.toml` or they will be silently omitted from the package.

**Without packaging configuration**:
- Development works (file exists locally)
- Production installs fail (pricing.yaml missing from wheel)
- Silent regression: `load_pricing_data()` returns `{}`, costs show $0.00

### 5.2 Solution

**Update `pyproject.toml`** to include pricing.yaml in package distribution:

```toml
[tool.setuptools.package-data]
agentdeck = [
    "py.typed",
    "config/*.yaml",  # ← ADD THIS LINE
]
```

**Alternative (if using `include-package-data = true`)**:

Ensure `MANIFEST.in` includes:
```
recursive-include src/agentdeck/config *.yaml
```

### 5.3 Validation

**Phase C Testing MUST verify**:
1. Build wheel: `python -m build`
2. Inspect wheel contents: `unzip -l dist/agentdeck-*.whl | grep pricing.yaml`
3. Verify pricing.yaml is present in wheel
4. Install from wheel: `pip install dist/agentdeck-*.whl`
5. Test that pricing.yaml is accessible at runtime

**Failure Mode**:
If pricing.yaml is missing from wheel, `load_pricing_data()` will:
- Log: `WARNING: pricing.yaml not found at .../pricing.yaml - costs will be zero`
- Return: `{}`
- Result: TokenUsageTracker shows $0.00 for all models

### 5.4 Success Criteria (Phase 1)

**Added to Phase 1 Success Criteria**:
- [ ] pricing.yaml packaged correctly (pyproject.toml updated)
- [ ] Wheel inspection shows pricing.yaml present
- [ ] Fresh install from wheel can load pricing data

## 6. Python API (pricing.py)

### 6.1 Module Interface

```python
def load_pricing_data() -> Dict[str, Any]:
    """
    Load pricing data from pricing.yaml file.

    Returns:
        Dict containing pricing data, or empty dict if file not found.

        Structure:
        {
            "openai": {
                "gpt-4o-mini": {
                    "input_cost_per_million": 0.15,
                    "output_cost_per_million": 0.60,
                    "last_updated": "2025-01-15",
                    "tier": "standard"
                },
                "_default": {...}
            },
            "anthropic": {...},
            "metadata": {...}
        }

    Behavior:
        - Caches data globally on first call (singleton pattern)
        - Validates YAML structure before caching
        - Returns empty dict if file not found (logs WARNING)
        - Raises ValueError if validation fails
        - Returns empty dict for generic load/parsing errors after logging

    Error Handling:
        - File not found: Returns {}, logs WARNING
        - YAML parsing error or other unexpected load failure: Returns {}, logs ERROR
        - Validation error (V0-V6): Raises ValueError, logs ERROR

        The function raises ValueError for any structural issues (malformed YAML
        or failed validation). It returns {} for missing files and generic load
        failures where costs can safely default to zero.

    Raises:
        ValueError: If YAML structure is invalid (malformed YAML or validation failed)

    Examples:
        >>> load_pricing_data()  # File exists and valid
        {"openai": {...}, "anthropic": {...}}

        >>> load_pricing_data()  # File not found
        {}  # Returns empty dict, logs WARNING

        >>> load_pricing_data()  # File contains invalid YAML
        ValueError: pricing.yaml validation failed: pricing.yaml root must be a dict, got list
    """
```

```python
def get_model_pricing(provider: str, model: str, allow_missing: bool = False) -> Tuple[float, float]:
    """
    Get pricing for a specific provider/model combination.

    Args:
        provider: Provider name (e.g., "openai", "anthropic", "google")
        model: Model identifier (e.g., "gpt-4o-mini", "claude-3-5-sonnet-20241022")
        allow_missing: If False (default), raises ValueError for unknown provider/model.
                      If True, returns (0.0, 0.0) with a WARNING log.

    Returns:
        Tuple of (input_cost_per_million, output_cost_per_million)

    Lookup Behavior:
        1. Try exact model match in provider's pricing
        2. If not found, try provider's _default pricing
        3. If still not found:
           - allow_missing=False: raise ValueError with helpful message
           - allow_missing=True: log WARNING and return (0.0, 0.0)

    Raises:
        ValueError: If provider/model not found and allow_missing=False

    Examples:
        >>> get_model_pricing("openai", "gpt-4o-mini")
        (0.15, 0.60)

        >>> get_model_pricing("openai", "gpt-5-ultra")  # Exact match not found, uses _default
        (5.00, 15.00)  # Logs INFO about using default

        >>> get_model_pricing("openai", "typo-model")  # No default
        ValueError: No pricing found for openai/typo-model. Available models: [...]

        >>> get_model_pricing("openai", "typo-model", allow_missing=True)
        (0.0, 0.0)  # Logs WARNING
    """
```

```python
def calculate_cost(provider: str, model: str, prompt_tokens: int, completion_tokens: int) -> float:
    """
    Calculate the total cost for an LLM API call.

    Args:
        provider: Provider name
        model: Model identifier
        prompt_tokens: Number of input tokens (prompt, context, system message)
        completion_tokens: Number of output tokens (response)

    Returns:
        Total cost in USD (input_cost + output_cost)

    Behavior:
        - Calls get_model_pricing(provider, model, allow_missing=False)
        - If ValueError raised (unknown provider/model):
          * Logs WARNING with helpful message
          * Returns 0.0 (backward compatibility)
          * Error repeats on every call (not cached, ensures visibility)

    Formula:
        input_cost = (prompt_tokens / 1_000_000) * input_cost_per_million
        output_cost = (completion_tokens / 1_000_000) * output_cost_per_million
        total_cost = input_cost + output_cost

    Examples:
        >>> calculate_cost("openai", "gpt-4o-mini", 1000, 500)
        0.00045  # (1000/1M * 0.15) + (500/1M * 0.60) = 0.00015 + 0.0003

        >>> calculate_cost("openai", "typo-model", 1000, 500)
        0.0  # Logs WARNING, returns 0.0 for backward compatibility
    """
```

### 6.2 Internal Functions

```python
def _validate_pricing_structure(data: Dict) -> None:
    """
    Validate pricing.yaml structure to catch typos and malformed data.

    Args:
        data: The loaded pricing data (expected to be a dict)

    Raises:
        ValueError: If structure is invalid

    Validation Checks:
        - V0: Root structure (MUST be dict, not list/scalar/null) - CRITICAL
        - V1: Required fields (input_cost_per_million, output_cost_per_million)
        - V2: Type safety (costs are numeric, not strings)
        - V3: Non-negative costs (no negative values)
        - V4: Provider structure (providers are dicts)
        - V5: Metadata exclusion (skip 'metadata' key)
        - V6: Special keys (skip keys starting with '_')

    Implementation Note:
        MUST check isinstance(data, dict) BEFORE calling .items() to prevent
        AttributeError when YAML root is malformed (list, scalar, null).
        This ensures "fail fast & loudly" behavior instead of silently
        returning {} via the broad except handler in load_pricing_data().

    Examples:
        >>> _validate_pricing_structure({"openai": {"gpt-4o": {"input_cost_per_million": 2.5, "output_cost_per_million": 10.0}}})
        # No exception - valid structure

        >>> _validate_pricing_structure([{"openai": "invalid"}])  # List instead of dict
        ValueError: pricing.yaml root must be a dict, got list

        >>> _validate_pricing_structure({"openai": {"gpt-4o": {"input_cost_per_million": "2.5"}}})
        ValueError: Invalid input_cost_per_million for openai/gpt-4o: expected number, got str

        >>> _validate_pricing_structure({"openai": {"gpt-4o": {"input_cost_per_million": -1.0}}})
        ValueError: Negative cost for openai/gpt-4o: input_cost_per_million=-1.0
    """
```

## 7. Integration with LLMPlayer

### 7.1 Metadata Requirements

**M1: LLMPlayer MUST capture usage_info**
Every LLMPlayer (GPTPlayer, ClaudePlayer, GeminiPlayer) MUST capture token usage in action metadata:

```python
{
    "usage_info": {
        "prompt_tokens": int,      # Input tokens
        "completion_tokens": int,  # Output tokens
        "total_tokens": int        # Optional: prompt + completion
    }
}
```

**M2: Metadata flows through ActionResult**
The `usage_info` dict MUST be included in `ActionResult.metadata` returned by `Player.decide()`.

**M3: Metadata preserved in events**
The `usage_info` dict MUST be preserved in GAMEPLAY events emitted by Console.

### 7.2 Provider Identification

**P1: LLMPlayer MUST expose provider name**
Every LLMPlayer subclass MUST define a class-level `PROVIDER` constant:

```python
class GPTPlayer(LLMPlayer):
    PROVIDER = "openai"

class ClaudePlayer(LLMPlayer):
    PROVIDER = "anthropic"

class GeminiPlayer(LLMPlayer):
    PROVIDER = "google"
```

**P2: Model name from config**
The model name is already available via `player.model` attribute (from Player.__init__).

**P3: TokenUsageTracker access**
TokenUsageTracker can access provider via `player.PROVIDER` and model via `player.model`.

## 8. Integration with TokenUsageTracker

### 8.1 Cost Calculation Flow

```python
class TokenUsageTracker(Spectator):
    def on_gameplay(self, event: Event) -> None:
        data = event.data
        action = data.get("action")

        if action and isinstance(action, dict):
            metadata = action.get("metadata", {})
            usage_info = metadata.get("usage_info")

            if usage_info and isinstance(usage_info, dict):
                prompt_tokens = usage_info.get("prompt_tokens", 0)
                completion_tokens = usage_info.get("completion_tokens", 0)

                # Get player object from somewhere (Console context?)
                player = self._get_player_from_event(event)
                provider = player.PROVIDER
                model = player.model

                # Calculate cost
                from agentdeck.utils.pricing import calculate_cost
                cost = calculate_cost(provider, model, prompt_tokens, completion_tokens)

                # Track cost
                self._costs[player.name] += cost
```

**T1: Defensive extraction**
TokenUsageTracker MUST validate `usage_info` is a dict before accessing fields.

**T2: Graceful fallback**
If `usage_info` is missing or invalid, TokenUsageTracker MUST skip cost calculation (no crash).

**T3: Zero-cost tolerance**
TokenUsageTracker MUST display `$0.00` if pricing data is missing (not error).

## 9. Error Handling

### 9.1 Missing pricing.yaml

**Behavior**: Return empty dict from `load_pricing_data()`, log WARNING.

```
WARNING: pricing.yaml not found at /path/to/pricing.yaml - costs will be zero
```

**Impact**: `calculate_cost()` returns 0.0 for all calls.

### 9.2 Invalid YAML structure

**Behavior**: Raise ValueError from `load_pricing_data()`, log ERROR.

```
ERROR: pricing.yaml validation failed: Missing 'input_cost_per_million' for openai/gpt-4o
```

**Impact**: ValueError propagates to caller. Costs cannot be calculated. This is INTENTIONAL - validation failures should fail loudly rather than silently default to $0.00.

**Rationale**: Unlike missing file (acceptable scenario), malformed YAML indicates a configuration error that should be fixed immediately. Failing loudly ensures the issue is noticed and corrected.

### 9.3 Unknown provider/model

**Behavior (allow_missing=False)**: Raise ValueError from `get_model_pricing()`.

```python
ValueError: No pricing found for openai/gpt-5-ultra. Available providers: ['openai', 'anthropic', 'google']. Available models for 'openai': ['gpt-4o-mini', 'gpt-4o', '_default']. Set allow_missing=True to return $0.00 instead of raising.
```

**Behavior (allow_missing=True)**: Return (0.0, 0.0), log WARNING.

```
WARNING: No pricing data found for openai/gpt-5-ultra. Returning $0.00. This likely indicates a typo in provider or model name. Available providers: ['openai', 'anthropic', 'google']
```

**Behavior in calculate_cost()**: Catch ValueError, log ERROR, return 0.0.

```
ERROR: Cost calculation failed: No pricing found for openai/typo-model. Available providers: [...]. Returning $0.00. This error will repeat for every API call until fixed.
```

### 9.4 Design Rationale

**R1: Never crash on missing pricing**
AgentDeck experiments should never crash due to missing pricing data. Researchers care more about agent behavior than costs.

**R2: Loud warnings for typos**
If provider or model names are wrong, log ERROR on every API call (not cached) so researchers notice and fix it.

**R3: Zero-cost fallback**
Return 0.0 when pricing unknown (backward compatible with existing code that might not handle exceptions).
